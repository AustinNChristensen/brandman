# Security policy

## Reporting a vulnerability

Please do not open a public issue, pull request or discussion for a security
problem.

Report it privately through GitHub:
[Report a vulnerability](https://github.com/AustinNChristensen/brandman/security/advisories/new).
Include the affected version or commit, steps to reproduce, and the impact you
expect. We will acknowledge the report, keep you updated, and credit you in
the advisory if you want.

## Supported versions

BrandMan is early (0.1.x). Fixes go into the latest release on
[PyPI](https://pypi.org/project/brandman/) and into `main`. Older releases do
not get backports.

## Scope

This policy covers this repository, the `brandman` package and the
`ghcr.io/austinnchristensen/brandman` image. For the hosted BrandMan Cloud
service at <https://usebrandman.com>, use the same private reporting link.
